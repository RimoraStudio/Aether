# Security Policy

## Supported Versions

The latest minor release of Aether is supported and receives security updates when available. Releases are published through the upstream Deskflow release infrastructure:

https://github.com/neang-mengseang/Aether/releases

## Reporting a Vulnerability

Please report vulnerabilities on the upstream issue tracker as bugs so the original developers are aware:

https://github.com/neang-mengseang/Aether/issues

Make sure to mention that the issue affects Aether, especially if it relates to rebrand-specific changes.

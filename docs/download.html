Installation guide

Step-by-step instructions for each platform.

Install on Windows

  1. Download the latest aether-windows-x64.msi using the Windows button above.
  2. Run the installer and follow the prompts. Administrator privileges are required.
  3. Launch Aether from the Start menu or desktop shortcut.
  4. On the first PC choose Server, on the others choose Client.
  5. Arrange your screens in the GUI by dragging them to match your physical layout.
  6. Set hotkeys for screen switching if desired, then start the server.

Aether runs in the system tray. Right-click the tray icon to start, stop, or reconfigure the server at any time.

macOS support coming soon

macOS is not yet available. Aether currently supports Windows and Linux. Check back later or follow the project on GitHub for updates.

In the meantime, you can build from source to try Aether on macOS in development.

Install on Linux

  • Flatpak: build from deploy/linux/flatpak/org.aether.aether.yml with flatpak-builder.
  • Debian/Ubuntu: install the .deb package using the Linux button above, then run sudo apt install ./aether-*.deb.
  • Fedora/openSUSE: install the .rpm package using sudo dnf install aether-*.rpm or sudo zypper install aether-*.rpm.
  • Arch: run makepkg on the generated PKGBUILD in the build output, then install with pacman -U.

On Linux, Aether supports both X11 and Wayland. The correct backend is selected automatically based on your session type. For Wayland, the portal-based input capture is used where available.

Build from source

See the build guide for full details. Quick start:

git clone https://github.com/RimoraStudio/Aether.git cd Aether cmake -S . -B build cmake --build build

You will need CMake 3.24+, Qt 6.7+, and OpenSSL 3.0+. Most other dependencies are fetched automatically by CMake. See the build guide for platform-specific notes and packaging instructions.

System requirements

Windows 10 or later, or a modern Linux distribution with X11 or Wayland. macOS support is coming soon. Network connectivity between all machines on the same LAN.

Package managers

Aether supports Flatpak, deb, rpm, and Arch PKGBUILD packages. Once a release is published, the download buttons above will link directly to the correct asset for each platform.

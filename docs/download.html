Installation guide

Step-by-step instructions for each platform.

Install on Windows

  1. Download the latest aether-windows-x64.msi or .exe using the buttons above. The MSI installer is recommended as it configures firewall rules automatically.
  2. Run the installer and follow the prompts. Administrator privileges are required.
  3. Launch Aether from the Start menu or desktop shortcut.
  4. On the first PC choose Server, on the others choose Client.
  5. Arrange your screens in the GUI by dragging them to match your physical layout.
  6. Set hotkeys for screen switching if desired, then start the server.

Aether runs in the system tray. Right-click the tray icon to start, stop, or reconfigure the server at any time. The 7Z archive is a portable option that does not require installation, but you will need to configure firewall rules manually.

Install on Linux

  • Debian/Ubuntu/Mint: download the .deb package, then run sudo apt install ./aether-*.deb.
  • Fedora/openSUSE: download the .rpm package, then run sudo dnf install aether-*.rpm or sudo zypper install aether-*.rpm.
  • Other distributions: extract the .tar.gz archive and run the binary directly. You may need to install Qt 6 and OpenSSL dependencies manually.

On Linux, Aether supports both X11 and Wayland. The correct backend is selected automatically based on your session type. For Wayland, the portal-based input capture is used where available.

Build from source

See the build guide for full details. Quick start:

git clone https://github.com/RimoraStudio/Aether.git cd Aether cmake -S . -B build cmake --build build

You will need CMake 3.24+, Qt 6.7+, and OpenSSL 3.0+. Most other dependencies are fetched automatically by CMake. See the build guide for platform-specific notes and packaging instructions.

System requirements

Make sure your machines meet these requirements before installing.

Operating system

  • Windows 10 or later (x64)
  • Linux with X11 or Wayland (x64)
  • Ubuntu 24.04+, Fedora 40+, or equivalent

Network

  • All machines on the same LAN
  • Port 24800 accessible (TCP)
  • Firewall configured to allow Aether

Runtime libraries

  • Qt 6.7+ (bundled in packages)
  • OpenSSL 3.0+ (bundled in packages)
  • Linux: libei, libportal, X11 or Wayland

Package formats

Choose the format that fits your platform and workflow.

Windows

MSI
MSI Installer

Recommended. Includes firewall rules and service registration. Installs to Program Files. Supports enterprise deployment via Group Policy.

EXE
EXE Bootstrapper

Lightweight wrapper around the MSI. Same contents, smaller initial download. Good for users who prefer .exe installers.

7Z
Portable Archive

No installation required. Extract and run. You must configure firewall rules manually. Ideal for USB drives or restricted environments.

Linux

DEB
DEB Package

For Debian, Ubuntu, Mint, and derivatives. Install with sudo apt install ./aether-*.deb. Dependencies are resolved automatically.

RPM
RPM Package

For Fedora, openSUSE, RHEL, and derivatives. Install with sudo dnf install aether-*.rpm or sudo zypper install aether-*.rpm.

TGZ
tar.gz Archive

Generic binary archive for any Linux distribution. Extract and run. You may need to install Qt 6 and OpenSSL dependencies manually.

SHA-256 checksums are included with every release. Verify downloads by comparing the checksum in sums.txt against your file before installing.

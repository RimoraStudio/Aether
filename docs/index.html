Open source, cross-platform input sharing

One desk.
Many computers.

Aether lets you control multiple computers with a single keyboard and mouse. Move the cursor from one screen to the next, share the clipboard, and keep everything encrypted over the network.

Built for seamless workflows

Aether handles the networking so your devices feel like one desktop.

Seamless screen crossing

Drag the cursor off one screen and onto another without pressing any buttons. Aether tracks edge positions so the transition feels instant and natural.

Shared clipboard

Copy and paste text and images between systems automatically. Your clipboard content travels with the cursor as it crosses screen boundaries.

TLS encryption

Server and client traffic is encrypted with TLS to keep your input data private. Aether generates and manages certificates for you automatically.

Cross-platform

Windows, macOS, and Linux. X11 and Wayland are both supported on Linux, so Aether works across mixed-OS setups without compromise.

Protocol compatibility

Works with the Synergy and Barrier wire protocols for broad interoperability. Connect Aether to existing Synergy or Barrier clients and servers.

Qt-based GUI

Arrange screens visually, set hotkeys, and configure autostart without editing config files. The GUI lives in your system tray for quick access.

How it works

Aether runs as a server on your primary machine and as a client on each secondary machine.

1

Install

Download and install Aether on every computer you want to connect.

2

Configure

Set one machine as server, arrange screens in the GUI, and add clients by hostname.

3

Share

Move your cursor across screen edges. One keyboard and mouse, many computers.

Open source, cross-platform input sharing

One desk.
Many computers.

Aether lets you control multiple computers with a single keyboard and mouse. Move the cursor from one screen to the next, share the clipboard, and keep everything encrypted over the network.

Download Aether View source on GitHub

Everything you need to share input

Aether handles the messy networking so your devices feel like one desktop.

Seamless screen crossing

Drag the cursor off the edge of one screen and onto another. No button pressing, no manual switching.

Shared clipboard

Copy text and images on one machine and paste on another. It works in both directions automatically.

TLS encryption

Server and client traffic is encrypted so your keystrokes and clipboard data stay private on the network.

Cross-platform

Run the server on Windows, macOS, or Linux and mix clients across all three. X11 and Wayland are both supported.

Protocol compatibility

Aether speaks the Synergy and Barrier wire protocols, so it can connect alongside existing tools on your network.

Easy configuration

The Qt-based GUI lets you arrange screens, set hotkeys, and configure autostart without editing files.

How it works

1

Set the server

Pick the computer that owns the physical keyboard and mouse and run Aether in server mode.

2

Arrange screens

Drag each client screen into the grid to match how your monitors are physically laid out.

3

Move the cursor

Slide the cursor off one screen edge and it instantly appears on the next machine. That is it.

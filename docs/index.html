Open source, cross-platform input sharing

One desk.
Many computers.

Aether lets you control multiple computers with a single keyboard and mouse. Move the cursor from one screen to the next, share the clipboard, and keep everything encrypted over the network.

Download Aether View source on GitHub

Built for seamless workflows

Aether handles the networking so your devices feel like one desktop.

Seamless screen crossing

Drag the cursor off one screen and onto another without pressing any buttons.

Shared clipboard

Copy and paste text and images between systems automatically.

TLS encryption

Server and client traffic is encrypted to keep your input data private.

Cross-platform

Windows, macOS, and Linux. X11 and Wayland are both supported.

Protocol compatibility

Works with the Synergy and Barrier wire protocols for broad interoperability.

Qt-based GUI

Arrange screens, set hotkeys, and configure autostart without editing files.

About Aether

An open-source keyboard and mouse sharing utility for Windows, macOS, and Linux.

Aether lets one keyboard and mouse control multiple computers on the same local network. The cursor moves from one screen to the next as if the machines were a single desktop. Clipboard sharing and TLS encryption are built in, so your input data stays private on the wire.

Aether is built with C++20 and Qt 6, and uses the Synergy and Barrier wire protocols for broad interoperability. It runs as a server on your primary machine and as a client on each secondary machine, communicating over your existing LAN.

Why Aether

Hardware KVM switches are expensive and require physical cable switching. Software alternatives often lack encryption, cross-platform support, or active maintenance. Aether combines seamless screen crossing, clipboard sharing, TLS encryption, and broad protocol compatibility in a single open-source package.

Key features

  • Seamless cursor crossing: move the cursor off one screen edge and onto the next without any hotkey or button press.
  • Clipboard sharing: copy on one machine, paste on another. Text and images both work.
  • TLS encryption: all client-server traffic is encrypted. Certificates are generated and managed automatically.
  • Cross-platform: Windows, macOS, and Linux with both X11 and Wayland support.
  • Protocol compatibility: interoperates with Synergy and Barrier clients and servers.
  • Qt-based GUI: visual screen arrangement, hotkey configuration, and system tray integration.
  • Open source: GPL-2.0 with OpenSSL exception. No telemetry, no accounts, no lock-in.

Roadmap

What is being built next for Aether.

Virtual display streaming

Turn a second machine into a wireless monitor for your main machine. No HDMI cable. The main machine creates a virtual display using an IddCx driver, streams the screen content over LAN with H.264/H.265 encoding, and the sub machine renders it fullscreen. Input from the sub machine flows back to the main machine.

Planned milestones:

  • Milestone 1: Virtual display driver integration and screen capture (POC)
  • Milestone 2: Video encoding, network streaming, and client-side rendering
  • Milestone 3: Input forwarding from display client back to server
  • Milestone 4: GUI integration, driver bundling, and production release

Read the full technical design in the virtual display plan.

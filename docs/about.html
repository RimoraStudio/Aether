About Aether

Aether is an open-source keyboard and mouse sharing utility.

Aether lets one keyboard and mouse control multiple computers on the same network. The cursor moves from one screen to the next as if the machines were a single desktop. Clipboard sharing and TLS encryption are built in.

Aether is based on Deskflow, which itself continues the lineage of the original Synergy project. Aether is an independent rebrand and is not affiliated with the upstream Deskflow project.

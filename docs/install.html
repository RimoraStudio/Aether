Install Aether

Choose your platform for step-by-step instructions.

Install on Windows

  1. Download the latest aether--windows-x64.msi from the download page.
  2. Run the installer and follow the prompts.
  3. Launch Aether from the Start menu or desktop shortcut.
  4. On the first PC choose Server, on the others choose Client, then arrange your screens.

Install on macOS

  1. Download the latest aether--macos.dmg from the download page.
  2. Open the DMG and drag Aether into Applications.
  3. Launch Aether from Applications and grant accessibility permissions when prompted.
  4. Configure the server, then add clients.

Install on Linux

  • Flatpak: build from deploy/linux/flatpak/org.aether.aether.yml.
  • Debian/Ubuntu: install the .deb package from the download page.
  • Fedora/openSUSE: install the .rpm package from the download page.
  • Arch: run makepkg on the generated PKGBUILD in the build output.

Build from source

See the build guide for full details. In short:

cmake -S . -B build cmake --build build

You will need CMake 3.24+, Qt 6.7+, and OpenSSL 3.0+. Most other dependencies are fetched automatically.
